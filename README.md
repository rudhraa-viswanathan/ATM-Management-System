# 🏧 ATM Management System

A simple ATM Management System developed using **Core Java**. This project simulates basic ATM operations through a console-based application and demonstrates object-oriented programming concepts.

---

## 📌 Features

- 🔐 User Login Authentication
- 💰 Balance Enquiry
- 💵 Cash Deposit
- 💸 Cash Withdrawal
- 🔑 PIN Change
- 📜 Transaction History
- 🔄 Continuous ATM Menu
- ✅ Input Validation

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/rudhraa-viswanathan/ATM-Management-System.git
```

2. Open the project in IntelliJ IDEA.

3. Build the Maven project.

4. Run:

```
ATMApplication.java
```
